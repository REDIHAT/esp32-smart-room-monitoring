ESP32 Smart Room Monitoring

Flash precompiled ESP-IDF 4.4.7 firmware directly from your browser without installing any tools.

⚠️ Web Serial is not supported in this browser. Please open this page in Google Chrome, Microsoft Edge, or Opera on Windows, Mac, or Linux. ⚠️ Web Serial is only supported over HTTPS or localhost. Offset: 0x0 • Single 4MB Merged Image
📋 Quick Flashing Steps:
  1. Plug your ESP32 DevKit V1 into your computer via a USB data cable.
  2. Click the blue "Connect & Install Firmware" button above.
  3. Select your ESP32's serial port (e.g. CP2102 or CH340) and click Connect.
  4. Click Install ESP32 Smart Room Monitoring and confirm.
  5. Wait for the progress bar to reach 100%. Once done, press the EN / RST button on the ESP32!

🔌 Hardware Wiring Reference

Component Pin ESP32 Pin Connection Notes
DHT11 VCC 3V3 3.3V Power
DHT11 DATA D4 (GPIO 4) 1-Wire bidirectional data
DHT11 GND GND Common ground
MQ-2 VCC VIN (5V) Heater coil requires 5V
MQ-2 GND GND Common ground
MQ-2 AO D34 (GPIO 34) Via 22kΩ + 10kΩ voltage divider (safe max 1.56V)
